# ML Practice

This repository is where I practice machine learning. More projects will be added over time.

## Projects

- [Titanic survival prediction](./titanic-ml): A classification project using **Logistic Regression** to predict passenger survival. It explores the Titanic dataset, prepares features such as sex, age, passenger class, fare, and port of embarkation, then evaluates the model with a train/test split and cross-validation.

- [NYC Yellow Taxi Trips](./nyc-yellow-taxi-trips): An exploratory regression project using the **September 2026 NYC Yellow Taxi dataset** to predict taxi fare from trip distance, pickup time, and day of the week. It includes data cleaning, EDA, feature engineering, and model experimentation to understand how trip characteristics affect fare amounts.
